# Seán Mac Ginnea — Portfolio Website

A three-page personal CV and project portfolio built with HTML, CSS and JavaScript. Uses a decorated, professional navy-and-blue design with a responsive layout, mobile navigation, project filters and the original portrait photograph.

## Files

- `index.html` — Home, profile, featured projects, education, work and Accio Work Campus Ambassador experience
- `projects.html` — Six projects, including coursework and work in progress
- `contact.html` — Contact links and interests
- `styles.css` — Shared styles and responsive rules
- `script.js` — Navigation, filtering, copy email button and current year
- `assets/sean-portrait.png` — Photograph recovered from the earlier CV supplied for this project
- `assets/favicon.svg` — SMG monogram

## Publish to GitHub Pages

1. Extract the ZIP.
2. Upload **the contents of the folder**, not the parent folder, to the root of the GitHub repository `SMG2006-HTML/Se-ns-CV` on branch `main`. Keep the `assets` folder intact.
3. In Settings → Pages, use either **Deploy from a branch** (main, root) or a working **GitHub Actions** workflow. Use one publishing method rather than two competing deployments.
4. Visit `https://smg2006-html.github.io/Se-ns-CV/` after the deployment succeeds.

No Node.js, package manager, build command or backend is necessary. Open `index.html` locally to preview it.

## Before sharing publicly

- Confirm the public email address and telephone number, which appear on the contact page.
- Review project descriptions against your own finished work. The Flask app is correctly identified as in progress; the GAA platform is presented as a design project, not a finished app.
- Optionally add links to individual GitHub repositories once they are published; no repository URLs have been invented.
- Fonts use Google Fonts when online, with system-font fallbacks when offline.
